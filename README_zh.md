# idv.rayawa.top

[English](README.md) | 简体中文

用于第五人格段位进度规划的浏览器工具。

归档项目，保留用于参考。

## 项目概述

单页界面计算赛季段位目标的进度，显示剩余天数、日均所需积分及历史记录，计算在浏览器中完成。

## 技术栈与依赖

HTML、JavaScript 及 CDN 加载的 Tailwind CSS，并使用外部视觉资源。需要浏览器，可选静态服务器；CDN 资源需要网络。

## 文件结构

- `index.html` — 界面、样式与计算逻辑
- `CNAME` — 自定义域名配置
- `favicon.ico` — 站点图标

## 快速上手

在仓库根目录启动静态服务器，以正确加载绝对路径资源：

```bash
python3 -m http.server 8000
```

打开 `http://localhost:8000/`。直接编辑 HTML 和静态资源，无需前端构建。

输入当前进度与目标数值，查看计算出的每日计划。
